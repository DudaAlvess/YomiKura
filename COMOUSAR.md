# 📚 YomiKura

> **Organize, converta e leia seus capítulos de mangá.**

Ferramenta em Python para organizar capítulos e transformar suas imagens em PDF.

## ⚙️ Requisitos

* Python 3.10+
* pip

## 📥 Instalação

Baixe o projeto, abra o terminal na pasta e execute:

```bash
pip install -r requirements.txt
```

## 🚀 Como usar

Execute:

```bash
python main.py
```

## 🔢 Capítulos

Adicione os capítulos desejados na lista `CAPITULOS`:

```python
CAPITULOS = [
    "86",
    "87",
    "88",
    "90",
]
```

Use **aspas e vírgula** em cada capítulo.
Capítulos especiais/decimais também podem ser adicionados, se suportados:

```python
"86.5",
```

Apenas os capítulos listados serão processados.

## 🖼️ PDF

O YomiKura organiza as imagens de cada capítulo e gera um PDF.
