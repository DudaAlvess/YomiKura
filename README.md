# YomiKura 📚

> **Reunindo histórias, página por página.**

## 🇯🇵 O que eu sou?

O **YomiKura** é uma ferramenta em Python para automatizar o download e a organização de capítulos de mangá.

Ele encontra as páginas, organiza os arquivos na ordem correta e cria um **PDF separado para cada capítulo**, mantendo tudo organizado em pastas.

### ✨ Recursos

- 📖 Vários capítulos de uma vez
- 🖼️ Download e organização das páginas
- 📄 Conversão para PDF
- 🔢 Suporte a capítulos como `167`, `167.1` e `167.2`
- 📊 Barra de progresso
- 🔄 Retomada de downloads
- 📁 Organização automática

## ⚠️ Aviso

O YomiKura **não fornece nem distribui conteúdo protegido por direitos autorais**.

Use-o somente com conteúdo que você tenha **permissão ou direito de baixar e armazenar**. É responsabilidade do usuário respeitar os direitos autorais, as leis locais e os termos de uso dos sites acessados.
